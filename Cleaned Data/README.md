# Customer Churn Scored Dataset

`Customer_Churn_Scored_PowerBI.csv`

This file is the scored output of the churn prediction model — the original customer dataset with two new columns appended (`Churn_Probability` and `Churn_Risk`). It is the data source for the companion Power BI dashboard and represents the final XGBoost model applied to the full 10,000-customer base.

---

## Overview

| | |
|---|---|
| **Rows** | 10,000 (one per customer) |
| **Columns** | 20 |
| **Source** | Original bank customer dataset, scored using the final trained XGBoost model (see `Customer_churn_prediction.ipynb`) |
| **Generated by** | `model_xgb.predict_proba()` applied to the full dataset, followed by tier assignment via `pd.cut()` |

---

---

## ⚠️ Important: `Complain` Column

During data cleaning, `Complain` was found to be 99.5% correlated with `Exited` — almost certainly recorded as a result of the churn decision (e.g., logged during account closure) rather than a genuine predictor of it. **It was excluded from model training** and should also be excluded from any driver/correlation analysis performed directly in Power BI, to avoid misleading conclusions. It is retained in this file only for traceability back to the original source data.

## `Churn_Risk` Tier Definition

Tiers were assigned based on `Churn_Probability` using the following cutoffs:

| Tier | Probability Range |
|---|---|
| Low | 0.00 – 0.30 |
| Medium | 0.31 – 0.60 |
| High | 0.61 – 0.85 |
| Very High | 0.86 – 1.00 |

| Tier | Customers | Actual Churn Rate |
|---|---|---|
| Low | 6,548 | 1.41% |
| Medium | 1,339 | 14.94% |
| High | 988 | 68.22% |
| Very High | 1,125 | 95.29% |

The steady rise in actual churn rate across tiers confirms the model's probability estimates are well-calibrated to real outcomes.

## Important Notes on Usage

1. **`Exited` vs. `Churn_Probability`** — `Exited` is the *historical, already-known* outcome the model was trained on. `Churn_Probability` is the model's *predicted* risk score. For ~80% of rows (customers who were in the training set), the probability may be slightly optimistic since the model has already "seen" that customer's outcome during training. The original 20% test-set predictions represent the more reliable, held-out estimate of real-world model performance (see the notebook for test-set-only metrics).
2. **This file mixes training and test data** — it was intentionally re-scored across the *entire* customer base to simulate how the model would be used in production (scoring all current customers), not to re-validate model accuracy. Model accuracy/precision/recall figures should be taken from the notebook's test-set evaluation, not derived from this file.
3. **Recommended derived measure** (built in Power BI as DAX, not included as a column here): `Priority Score = Churn_Probability × Balance` — used to rank customers by combined churn risk and account value for retention prioritization.
